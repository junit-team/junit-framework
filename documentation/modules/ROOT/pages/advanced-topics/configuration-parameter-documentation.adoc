= Documenting Configuration Parameters

Authors of test engines and JUnit Jupiter extensions may generate a machine-readable
overview of configuration parameters by annotating their configuration parameters
with `{PlatformConfigurationParameter}` and `{PlatformConfigurationParameterGroup}` from
the `org.junit.platform:junit-platform-configuration-api` artifact.

Processing the annotations with `org.junit.platform:junit-platform-configuration-processor`
will produce a `META-INF/junit-platform-configuration-metadata.json` file in the format
of {SpringBootConfigurationMetadata}. This file can then be used to generate documentation
or provide code completion by IDEs. An example is shown below.

The first paragraph from the Javadoc will be used to describe the property or group. If
the first paragraph contains tags these will be sensibly replaced.

When the `type` is an enum or interface, hints will be automatically generated. The first
paragraph of the enum constant is used to describe the enum value. If the allowed values
are not enumerable, {PlatformConfigurationParameterHints} can be used to provide
examples instead.


== Gradle

To use the annotation processor with Gradle, add the `junit-platform-configuration-api`
as a `compileOnly` dependency and enable the `junit-platform-configuration-processor` as
an `annotationProcessor`.

[source,kotlin,indent=0]
[subs=attributes+]
----
dependencies {
	annotationProcessor("org.junit.platform:junit-platform-configuration-processor:{version}")
	compileOnly("org.junit.platform:junit-platform-configuration-api:{version}")
}
----

== Maven

To use the annotation processor with Maven, add the `junit-platform-configuration-api`
as an `optional` runtime dependency and add the `junit-platform-configuration-processor`
to the `annotationProcessorPaths` of the `maven-compiler-plugin`.

[source,xml,indent=0]
[subs=attributes+]
----
<project>
	<!-- ... -->
	<dependencyManagement>
		<dependencies>
			<dependency>
				<groupId>org.junit</groupId>
				<artifactId>junit-bom</artifactId>
				<version>{version}</version>
				<type>pom</type>
				<scope>import</scope>
			</dependency>
		</dependencies>
	</dependencyManagement>

	<dependencies>
		<dependency>
			<groupId>org.junit.platform</groupId>
			<artifactId>junit-platform-configuration-api</artifactId>
			<optional>true</optional>
		</dependency>
	</dependencies>
	<build>
		<plugins>
			<plugin>
				<groupId>org.apache.maven.plugins</groupId>
				<artifactId>maven-compiler-plugin</artifactId>
				<version>{maven-compiler-version}</version>
				<configuration>
					<annotationProcessorPathsUseDepMgmt>true</annotationProcessorPathsUseDepMgmt>
					<annotationProcessorPaths>
						<path>
							<groupId>org.junit.platform</groupId>
							<artifactId>junit-platform-configuration-processor</artifactId>
						</path>
					</annotationProcessorPaths>
				</configuration>
			</plugin>
		</plugins>
	</build>
	<!-- ... -->
</project>
----

[[v6.2.0-M2-junit-jupiter-bug-fixes]]
==== Bug Fixes

* `@DefaultLocale` now also restores the default locale of each `Locale.Category`.

[[v6.2.0-M2-junit-jupiter-deprecations-and-breaking-changes]]
==== Deprecations and Breaking Changes

* ❓

[[v6.2.0-M2-junit-jupiter-new-features-and-improvements]]
==== New Features and Improvements

* Test execution cancellation is now also checked between before callbacks and
  lifecycle methods such as `@BeforeAll` and `@BeforeEach` methods.
* New `testSourceUri()` method in `TestTemplateInvocationContext` for supplying a custom
  test source `URI` for a `@TestTemplate` invocation.

== 5.14.5

*Date of Release:* November 26, 2026

*Scope:* Bug fixes and enhancements since 5.14.4

For a complete list of all _closed_ issues and pull requests for this release, consult the
link:{junit-framework-repo}+/milestone/124?closed=1+[5.14.5] milestone page in the JUnit
repository on GitHub.


[[v5.14.5-junit-platform]]
=== JUnit Platform

[[v5.14.5-junit-platform-bug-fixes]]
==== Bug Fixes

* A memory leak when using `NamespacedHierarchicalStore::getOrComputeIfAbsent` has been
  fixed.
  - Specifically, the store would retain a reference to the provided `defaultCreator`.
    Depending on how the store is used and what references the default creator holds, the
    impact can range anywhere from a trivial to a significant memory leak.
* `HierarchicalTestEngine` implementations now wait for the dynamic tests a node has
  already submitted even if the node's `execute()` method throws an exception. Previously,
  with parallel execution, such dynamic tests could finish after their parent, e.g. when
  the arguments source of a `@ParameterizedTest` or `@ParameterizedClass` or the children
  stream of a `DynamicContainer` threw an exception.


[[v5.14.5-junit-jupiter]]
=== JUnit Jupiter

[[v5.14.5-junit-jupiter-bug-fixes]]
==== Bug Fixes

* `@Nested` test classes declared in super classes of a test class are now discovered and
  executed even if they have the same simple name as a `@Nested` class declared in the
  test class.
